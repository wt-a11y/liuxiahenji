## 艺术家声明

> **在人与人交往的过程中，我们的行为会对他人产生正面或负面的影响。**
> **想引起"惕然"这样的思考：**
> **那么在这样的前提下，应该怎样控制自己的行为？**

本作品将这个抽象的伦理命题，转化为一种可感知的体验。

屏幕中央存在一个**抽象的有机体**。它冷蓝、安静，完整而未被打扰——这是"它"在遇到你之前的样子。

当你把手伸向摄像头，做出动作时：
- **每一个动作都会被记录。**
- 静止 0.8 秒后，动作会"凝结"为**记忆碎片**。
- 碎片缓慢漂向有机体，**渗透进它的内部**。
- 它的身体会因这些碎片**改变颜色、改变形状、留下暗疤痕**。

而你的动作是有"重量"的：
- **轻柔、缓慢的动作** —— 被识别为正向，碎片是暖琥珀色的晶体，渗透进有机体后会让它**渐渐变暖、变橙、变得舒展**，甚至能**缓慢治愈旧疤痕**。
- **剧烈、突变、加速的动作** —— 被识别为负向，碎片是冷紫黑色的尖锐晶体，渗透进有机体后会留下**暗色的疤痕**，疤痕持久不消退，**越积越多**。

观众会在反复的互动中看到：
- 一开始那个冷蓝色的存在，**被自己的善意染成温暖的金黄**；
- 或者，**被自己的粗暴覆盖上灰暗的冷紫**。

**这是作品想让观众"惕然"的事：**
你看不见自己的动作在别人身上留下了什么。但痕迹是真实的、累积的、几乎不可逆的。
**那么——下次伸出手之前，你是否愿意多想一秒？**

## 体验流程

![启动引导界面](docs/screenshots/02-intro-screen.png)
*（建议截图：启动时显示的引导文字"用力，是伤害；轻柔，是治愈"——这是作品观点的第一次明确表达）*

1. **启动引导**：屏幕中央出现作品标题与核心提问。
2. **开始交互**：将手放入摄像头视野，移动产生轨迹。
3. **动作结束**：静止 0.8 秒，动作会形成记忆碎片。
4. **碎片渗透**：碎片漂向有机体，被膜吸收，进入内部。
5. **结构变化**：有机体的颜色、内部纹理、外膜形状、疤痕都持续累积。
6. **反思结束**：按 ESC 后，屏幕展示本次互动的统计与反思文字。

![结束反思界面](docs/screenshots/03-reflection-screen.png)
*（建议截图：结束时的反思界面，会根据用户正/负向动作比例给出不同的反思文字，例如"温柔，是有回响的"或"在看不见的地方，痕迹依然存在"）*

## 核心逻辑

```
用户手部动作
   ↓ MediaPipe Hands 提取关键点
运动数据（速度、加速度、轨迹）
   ↓ 静止 0.8s 触发动作结束判定
动作分类（正向 / 负向 / 中性）
   ↓
记忆碎片生成
  · 正向碎片：暖琥珀、柔和、尖端不锐
  · 负向碎片：冷紫黑、尖锐、抖动剧烈
   ↓
碎片向有机体漂移 → 渗透过膜
   ↓
有机体接收影响
  · 颜色分阶段（L0→L4）从冷蓝渐变到暖橙（或被粗暴覆盖为冷紫）
  · 内部纹理脉络按等级染色
  · 负向行为 → 暗疤痕（持久、不可逆、只被正向缓慢治愈）
  · 记忆层叠加在膜上
   ↓
按 ESC 结束
   ↓
反思界面：根据本次正/负向比例输出对应文字
```

## 技术栈

- **Python 3.8+**
- **OpenCV** —— 摄像头捕获
- **MediaPipe Hands** —— 手部 21 个关键点追踪
- **Pygame** —— 视觉渲染、文字界面

---

## 文件结构

| 文件 | 说明 |
|------|------|
| `main.py` | 程序入口：启动引导 → 主循环 → 结束反思 |
| `hand_tracking.py` | MediaPipe 封装：提取手部位置与关键点 |
| `behavior_analysis.py` | 动作分析：速度、峰值速度、加速度方差；输出 `positive / negative / neutral` 分类 |
| `particle_system.py` | 记忆碎片：差异化正/负向视觉（颜色、形态、抖动） |
| `target_object.py` | 有机体：膜、内部纹理、脉络、记忆层、暗疤痕、L0-L4 颜色分阶段 |
| `interaction.py` | 交互管理：碎片接近膜判定、渗透处理 |
| `test_*.py` | 单元测试与诊断脚本（不参与主程序运行） |

## 安装与运行

```bash
# 安装依赖
pip install -r requirements.txt

# 运行项目（建议 Python 3.11）
py -3.11 main.py
```

### 操作

| 按键 | 作用 |
|------|------|
| 启动后任意键 | 进入主循环 |
| 移动手 + 静止 0.8s | 触发一次记忆碎片生成 |
| `C` | 清除所有痕迹（重置有机体） |
| `ESC` | 退出 → 显示反思界面 → 再次按任意键关闭 |

## 创作背景

在人与人之间最日常的相处里，**我们几乎不会意识到**：
一个语气、一个眼神、一次突发的急躁、一次被忽略的温柔——
对方接收到的是什么。

这件作品的目的是**让"影响"变得可见**。
不是给出一份情绪分数，而是让"痕迹"在屏幕里缓慢累积，让观众亲手看到：
- 当我以温柔对待它，它真的在变好；
- 当我以粗暴对待它，**伤痕真的很难消失**。

**它不会说一句话。但它会用自己的身体回答你。**
